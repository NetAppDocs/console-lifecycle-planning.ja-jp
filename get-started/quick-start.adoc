:allow-uri-read: 
:icons: font

[role="lead"]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"]前提条件を確認する
[role="quick-margin-para"]

link:../get-started/capacity-setup.html["ライフサイクル計画を設定するための手順を完了します"] 。

[role="quick-margin-para"]

[role="quick-margin-list"]
* link:../use/capacity-review-status.html["容量ステータスを確認する"] 。
